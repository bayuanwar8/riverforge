RIVERFORGE — bend the river, power the forge, hold the valley for seven nights. A 2D canvas game: by day you lay channels and mills to carry mountain water to the forge; by night you open and close floodgates in real time to power the forge and keep the flood away from the lantern-lit village. Survive seven nights, mind the pressure, mind the beavers.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080
```
